### Description

Python and PyTorch workflow for product-level operational-anomaly ranking using temporal, graph and hypergraph models. Includes software and technical documentation only; SupplyGraph input tables, trained checkpoints, manuscripts and stored research results are excluded. Comparisons are exploratory and do not establish operational disruption detection or causal effects.

Dr. Zohreh Kaheh designed the project based on her earlier work, provided the initial design and implementation teaching, supervised the initial implementation by Yuyang Zhang, and subsequently developed the code further. This account is supplied by the maintainer. Later revisions do not have a complete per-person edit history. Repository preparation and technical documentation involved AI assistance as described in ATTRIBUTION.
